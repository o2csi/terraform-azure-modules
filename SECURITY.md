# Security policy

This is a personal-infrastructure module repository. Please report a suspected
vulnerability by opening a private GitHub security advisory for this repository.
If private reporting is unavailable, open a minimal issue requesting a private
contact and do not include exploit details.

In scope are this repository's OpenTofu modules, example configuration, and
bootstrap scripts. Applied environments, credentials, and third-party Azure,
OpenTofu, Tailscale, or operating-system services are out of scope.

Reports receive a best-effort response. There is no bounty program and no
response or remediation SLA.
